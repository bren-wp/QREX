# QREX — Scan. Create. Share.

## Latest candidate: v1.0.6 · Android versionCode 106

QREX 1.0.6 redraws the adaptive launcher icon in the supplied blue Q/QR style and uses that same artwork on the Compose splash. Calendar event date selection is hardened against shorter months and leap-year changes. The dark-first UI, offline QR scanning, protected history, 23 languages and existing local data remain supported. This is a pending candidate until mandatory release checks succeed.

[Release details](docs/releases/v1.0.6.md) · [Latest downloads](https://github.com/bren-wp/QREX/releases/latest)

**Distribution notice:** Public GitHub APKs use disposable certificates and cannot update differently signed installations. Uninstalling can erase local history and Wi-Fi QR codes. The public GitHub AAB is not a Google Play upload artifact.
