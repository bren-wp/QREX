# QREX — Scan. Create. Share.

## Latest: v1.0.4 · Android versionCode 104

QREX remains an offline-first QR scanner and creator. This release adds monotonic camera-frame decode pacing to reduce repeated work, an open-source ZXing camera/gallery decoder, more automated regression coverage and a real seven-screen Android screenshot gallery.

[Release details](docs/releases/v1.0.4.md) · [Latest downloads](https://github.com/bren-wp/QREX/releases/latest) · [F-Droid status](docs/FDROID_DISTRIBUTION.md)

**Distribution notice:** public GitHub APKs are signed with disposable keys and cannot update differently signed installations in place; uninstalling can erase user data. QA candidates for Google Play and F-Droid need the correct separately authorized signing and store review. No Play/F-Droid publication is implied by a GitHub release.
