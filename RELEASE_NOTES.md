# QREX — Scan. Create. Share.

Scan, create, organize and export QR codes with a private and easy-to-use experience on Android and iPhone.

## Next production version — v1.0.0

**QREX 1.0.0 / build 100** is being prepared for Android and iOS. Only production-signed, explicitly approved binaries may appear in the future `v1.0.0` GitHub stable release. A passing CI build alone is not proof of Google Play or App Store readiness. Signing, real-device QA and release approval are required.

[QREX 1.0.0 release notes](docs/releases/v1.0.0.md) · [Production readiness checklist](docs/STORE_CHECKLIST.md)

## Historical versions and cleanup

Previous Android Flutter releases and native RC preview releases are being retired from public GitHub Releases. The production workflow will delete their **GitHub Releases and Git tags only after a verified, signed v1.0.0 release is available**. Until then, the existing legacy builds remain available; deleting them prematurely would leave users without an installable release.

The original sources, user-data compatibility logic and repository history are retained.

## Designed for privacy

QREX does not require an account and processes QR codes on the device. Scanning does not open an external link automatically. A user-exported PDF/ZIP archive can contain private QR content (including Wi-Fi passwords), and **is not encrypted**.
