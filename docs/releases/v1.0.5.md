# QREX 1.0.5 — Dark-first Android UI and stability regression fixes

Android application ID `com.brendigo.qrex` · `versionName 1.0.5` · `versionCode 105`.

## What's changed

- **Dark navy is the default for new installations.** Blue/cyan accents, higher-contrast selected navigation, coherent cards and controls, refreshed Scan, Create, Result, History, Favorites and More screens. The user may still choose light mode; upgrades preserve an explicitly saved light theme preference.
- Reworked the actual Kotlin/Jetpack Compose layout toward the supplied QREX visual references, not a screenshot-as-UI substitute. Buttons, scanner, creation, saved/favorites filters, encryption and PDF/ZIP exports remain real actions.
- **Fixed a confirmed CI regression:** a stale light-theme navigation test still asserted the removed `else cyan` expression, failing Android native CI and the F-Droid audit. The regression contract now checks dark-first defaults, light preference preservation, theme-aware navigation contrast and real palette tokens.
- Full final-source PR checks: Kotlin/unit/lint/R8, privacy/manifest/dependencies, F-Droid scanner/lint, screenshot capture of the running Android app, locale validation, and API 26, 31, 34, 35 and 36 emulator lifecycle/nav stress tests. Successful automation **does not guarantee** no intermittent OEM device crashes or certify exact visual pixel identity on every model.
- Local QR data, AES-GCM Android Keystore protection, offline CameraX/ZXing scanning, QR exports, Android-only package name and legacy Flutter history migration remain intact.

## Release files

- `QREX-Android-1.0.5.apk` — signed, installable **GitHub distribution only**.
- `QREX-Android-1.0.5.aab` — signed with a **disposable GitHub certificate**, **not approved for an existing Google Play upload**.
- `QREX-Android-1.0.5-Play-UNSIGNED-QA.aab` — **unsigned** candidate for subsequent signing by the **existing approved Play upload key**.
- `QREX-Android-1.0.5-FDroid-UNSIGNED-QA.apk` — **unsigned** open-source release QA candidate, not installed or F-Droid-approved without the F-Droid build/signing workflow.
- `android-splash.png`, `android-create.png`, `android-scan.png`, `android-wifi.png`, `android-result.png`, `android-history.png`, `android-saved.png`, `android-more.png` — eight actual debug-emulator screenshots (1080 × 1920), not AI mockups; generated and verified against the exact release commit.
- `SHA256SUMS.txt` — hashes for release binaries and images.

**Signing and local-data warning:** Each public QREX GitHub APK has a fresh throwaway signing key. The 1.0.5 GitHub APK **cannot update in place** from a differently signed 1.0.0–1.0.4 or Google Play installation. Uninstalling older QREX may permanently delete local QR history, saved Wi-Fi records and Android Keystore data. **Do not uninstall before protecting any required records.**

**Google Play:** The Play Console's already-used versionCode values and existing upload certificate must be verified. An unsigned AAB or a public GitHub-signed AAB is **not a ready-to-submit production update**.

**F-Droid:** The CameraX + ZXing scanner has no ML Kit dependency and is intended to meet FLOSS requirements, but CI success is not official F-Droid acceptance. A reproducible recipe, full license review, signing/index setup and any fdroiddata submission remain separate tasks.

Existing GitHub releases v1.0.0 through v1.0.4 remain available and unmodified.
