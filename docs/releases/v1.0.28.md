# QREX v1.0.28 — Result screen native 3D category glyphs

**Android:** com.brendigo.qrex · versionName 1.0.28 · versionCode 128 · minSdk 26 · targetSdk 36.

## Screen by screen
Splash and the Home live scanner retain the validated Compose design and functional 56dp flash controls. On the **Result** screen the existing 62dp category icon now chooses an original colored 3D gradient: blue for links and ordinary QR, green for Wi-Fi, red for phone actions and purple for calendar events. Each icon retains a 32dp vector, native colored 1dp border and 5dp elevation. No static promotional screenshot is inserted into the app.

All Copy, Share, Generate/Show QR, Favorite, Edit, Delete and Export callbacks remain connected. Wi-Fi password previews, clipboard actions and PNG export continue to require their established explicit consent. No new Internet permission, telemetry, migration, or sensitive-data logging.

## Distribution verification
**Candidate until published**: before GitHub v1.0.28 is created, require exact-main SHA Kotlin/JVM tests, Lint/R8, 23-language validation, P03 API 26/31/34/35/36 instrumentation, twelve authentic 1080×1920 Android screenshots, identical APK/AAB certificate fingerprints and verified SHA256SUMS. The reference board is perspective/composited; mathematical 1:1 pixel parity cannot be claimed without flat same-resolution screenshots.

**Signing warning:** The public GitHub APK/AAB is built with a disposable certificate, **not** the authorized Google Play upload key. It cannot update an app installed from Play or a differently signed APK in place. The Play-UNSIGNED-QA AAB must not be uploaded to Google Play. Keep user history and Wi-Fi credentials safe.
