# QREX 0.2.4 RC1 — More reliable QR scanning from photos

**Android and iPhone QA candidate only. Not a signed Google Play or App Store release.**

QREX helps you scan, generate, organize, save and export QR codes locally. It requires no account, does not automatically open scanned URLs, and does not send scans to an app-operated backend.

## Changes

- **Android gallery QR scanning:** Decode high-resolution images using a bounded power-of-two sample instead of allocating the full original bitmap. Inspect encoded size and image dimensions first, and retain EXIF rotation for common camera orientations. Reduce the risk of memory-related crashes when loading larger gallery photos.
- **iPhone gallery QR scanning:** Use an ImageIO thumbnail (maximum dimension 3072 pixels) for Vision decoding, preserving image orientation. Metadata checks and thumbnail creation run off the UI thread.
- **Corrupt image defense:** Reject images that exceed the supported 20 MB compressed-image threshold or 24 megapixels, and reject malicious dimension metadata without integer overflow.
- **Regression checks:** Android Kotlin tests cover decoder sample sizes and EXIF rotations; iOS XCTest covers image-size limits and extreme metadata values.
- **Release identity:** Android and iOS advance together to **0.2.4 / build 9**, keeping `com.brendigo.qrex` on both platforms; build 8 remains assigned to v0.2.3 RC1.
- **No privacy regressions intended:** Existing 23 language resources, locally stored history, protected Wi-Fi credentials, QR PDF/ZIP/PNG export, and Flutter-to-native compatibility remain in place.

## Verification required before an RC can be published

The release pipeline must confirm the exact Git SHA via Kotlin unit/instrumented tests, Android lint/R8/APK/AAB, Swift iPhone-simulator build/XCTest, unsigned iOS archive, Flutter analyze/tests, 23-language parity and actual Android/iPhone simulator screenshot checks. Successful checks are recorded by GitHub Actions rather than assumed from this document.

If those checks pass, the QA preview can include the debug-signed Android APK, unsigned Android AAB, unsigned iOS device archive, actual device-simulator screenshots and a SHA-256 checksum manifest. **These are QA artifacts, not store upload binaries.**

## Remaining distribution and privacy cautions

Test gallery decoding, live autofocus/torch, camera permissions, rotation/background lifecycle, PDF/ZIP/PNG export, migration and accessible layouts on physical Android and iOS devices. Inspect release binaries for dependency vulnerabilities. Authorized Play upload signing and Apple Developer provisioning are required separately before distributing through stores.

User-initiated PDF, ZIP, PNG and sharing operations may expose raw QR contents to the chosen destination. PDF/ZIP exports are **not encrypted** and may contain saved Wi-Fi details.
