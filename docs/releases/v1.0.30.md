## Screen 07 — More / Settings
- On standard-size dark Android phones the six live settings tiles remain arranged in three two-column rows: Theme, Language, Export, Privacy, Terms, About. On narrow screens or accessibility font scales these same actions stay usable as scrollable full-width rows.
- Native Compose category glyphs are aligned with the supplied reference: Brightness icon, globe, download, padlock, terms document, and information. Existing actions still open the real dialog or destination, not an inert mock.
- Each dark tile icon occupies a raised 40dp rounded plate with a 23dp vector, tinted luminous border, native elevation and a genuine RGB highlight. The highlight is intentionally white-to-transparent above the tinted surface, avoiding the flat same-RGB alpha bug.
- The About tile shows the actual installed package version instead of a frozen example. The real About dialog verifies the same version on-device.
- Clear History retains its separate red treatment and **requires explicit confirmation**. PDF export consent and stored QR security are unchanged.

## Validation and release policy
New tests: `tool/test_more_reference.py` for six icons, real handlers and gradients; `QREXMoreRootTest` instrumentation verifies working About dialog with installed-version text and no unintended preference changes. Existing tests still assert 23 locales, API 26/31/34/35/36, Compose UI, Kotlin/JVM, Lint/R8, real screenshot capture, privacy and data deletion safeguards.

Only after **all latest exact-commit CI gates pass on main** may GitHub workflow `github-release-1.0.30.yml` publish APK, AAB, Play-UNSIGNED-QA AAB, 12 real emulator screenshots and SHA256SUMS. Never substitute generated promo images.

**Signing limitation:** Public GitHub artifacts use a disposable CI signing identity, **not** the approved Google Play upload certificate. They cannot update a Play-installed QREX or an APK with a different certificate without uninstalling, which may destroy local saved QR data. The unsigned QA AAB cannot be submitted to Google Play.
