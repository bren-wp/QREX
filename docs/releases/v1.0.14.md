# QREX v1.0.14 — launcher and full-screen UX refinement

**Package:** `com.brendigo.qrex` · **versionName:** `1.0.14` · **versionCode:** `114` · **Android:** API 26+ · **Publisher:** Brendigo.

## Improvements

- Unify the electric-blue launcher adaptive background with the actual QREX splash/icon gradient. Preserve its Q/QR symbol, cyan scanner brackets and the hollow finder detail in Android's monochrome themed icon.
- Improve accessibility and touch geometry across the genuine Compose Scan, Create, Result, History, More, Language and Export surfaces; enlarge undersized History favorite/overflow targets, camera zoom controls and permission actions, and increase Result action rows and settings cards.
- Switch the four Create quick-type choices to a readable 2×2 grid on 320–419dp handsets and at elevated font scales; leave the QR preview sizing independent so it does not unexpectedly shrink on ordinary 393dp phones.
- Improve localized type wrapping and create header typography, plus Language row and PDF warning readability, while preserving the approved midnight-blue/cyan styling.
- Retain CameraX/ZXing live camera and gallery scanner, offline operation, four main tabs, PDF-only collection export, PNG saving, encrypted Wi-Fi history, and all **23** languages.
- Add Kotlin layout regression and source-contract checks for adaptive icons, screen touch targets, type labels and selected-state handling.

**Release QA:** Exact-commit Android CI (source tests, Kotlin, Lint, R8), localization coverage and real emulator screenshot capture must succeed before GitHub publishes its APK, AAB, unsigned Play QA AAB, ten actual UI screenshots and SHA256 manifests. API 26/31/34/35/36 stress tests complement this gate. Emulator captures and code contracts cannot certify 1:1 against reference artwork that is not stored in the repository; all OEM launcher shapes and physical cameras require manual QA.

**Critical signing warning:** GitHub APKs use a **disposable certificate** per public edition; the v1.0.14 APK **cannot update** existing GitHub/Google Play installations signed with another key. Do not uninstall an existing version without protecting your history and Keystore-encrypted saved Wi-Fi data. The public AAB and the explicitly unsigned Play QA bundle are **not Play-ready updates**; use the originally authorized upload key and a separate approved production workflow. Old releases remain unchanged.
