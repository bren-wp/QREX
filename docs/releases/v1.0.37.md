# QREX v1.0.37 — native policy, About, Scanner/Home and Splash pass

**Release candidate until verification and publication.** Android
`com.brendigo.qrex`, versionName `1.0.37`, versionCode `137`.
The current verified public version is v1.0.36.

## Screen 1: Privacy / Privatnost

- Preserve real `qrex-privacy-dialog`, offline summary, local persisted
  History switch and separate Close / full-policy actions.
- Use one native bordered summary card with an elevated 40dp shield plate
  and subtle real Compose RGB gradient, not a composited screenshot.
- Local history setting commits to existing preferences and **does not**
  delete saved data. Full-policy URL opens only with explicit tap.
- The lengthy translated summary scrolls below a persistent dialog title
  and above 48dp+ actions.

## Screen 2: Terms / Uvjeti

- Use the same 15dp native card radius, border and 40dp vector icon plate,
  with the complete existing localized terms summary preserved.
- Keep `qrex-terms-summary` readable in the 340dp bounded scrolling area;
  Close and external full-document controls remain independently accessible.

## Screen 3: About / O aplikaciji

- Retain installed app version from PackageManager, original QREX
  launch logo and translated tagline.
- Brendigo author and `brendigo.com` are grouped in a matching native
  raised card. The visual card is **not an unsolicited network action**:
  only the explicit `Open link` button launches the external site.
- No placeholder version strings or dev labels added.

## Screen 4: Scanner/Home

- The actual CameraX `PreviewView`, ZXing decoding, live overlay,
  gallery picker without camera permission and torch callbacks are
  unchanged. Frame data remains on-device.
- Scanner instruction uses a subtle native raised semi-opaque card over
  the camera, cyan border and responsive 12/14sp typography.
- Existing four-corner overlay, floating 56dp torch, bottom navigation
  and action touch targets remain real composables.

## Screen 5: Splash

- Retain real vector QREX badge and wave Canvas. Add a thin foreground
  cyan reflection in the bottom wave and a stable badge halo test tag.
- Preserve localized three-word cyan-highlight tagline, wordmark
  geometry, responsive footer and progress indicator. Short devices
  and accessibility font scaling still use a scroll layout.
- No generated marketing image is used for the actual UI.

## Regression and release gates

Android instrumented tests are extended for all five screens; source
guards cover the geometry tags and absence of unintended browser actions.
Release only on a freshly merged `main` commit after exact-SHA success
of Android native CI (Kotlin/JVM, Lint/R8, APK/AAB), translations for 23
offline languages, P03 emulator instrumentation APIs 26/31/34/35/36,
and authentic screenshot capture. GitHub publisher verifies checksums,
APK signature, AAB signature and all 16 expected assets.

**Visual validation limit:** perspective marketing reference cannot
establish numeric 0-pixel differences. Flat, equal-density reference PNGs
are needed for quantitative pixel-diff. Genuine emulator screenshots
are retained for inspection, not generated or shown as illustrations.

**Signing:** public GitHub release uses a disposable key and therefore
cannot update a Google Play installation or another differently signed APK
in place. The Play QA AAB is explicitly unsigned.
