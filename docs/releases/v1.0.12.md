# QREX 1.0.12 — dark-only app, PDF export and 23 languages

Package `com.brendigo.qrex`; versionName `1.0.12`; versionCode `112`.

- Keep QREX midnight-blue/cyan as the only theme, with existing Q/QR adaptive launcher and true CameraX/ZXing scanner. Remove settings theme toggle, light UI code, debug light fixture and old theme import; preserve existing obsolete preference bytes without using them.
- Remove ZIP export UI and writer. Preserve secure, user-selected Android Storage Access Framework PDF export, individual PNG export, confirmation and Wi-Fi confidentiality warnings.
- Regenerate the Android string resources for **all 23 supported languages** (Croatian included) from the complete canonical catalog; update privacy and legal text for PDF and language settings. Retain system-language option.
- Keep 4 main tabs, History/Favorites segment, all QR types and responsive layouts. No user-data schema or signing migration.
- Real QA capture requires 10 production-layout dark Android screenshots plus 7 responsive shots (320dp, 393dp, 1.6× font), and full Android API 26/31/34/35/36 P03 stress matrix, Kotlin tests, lint/R8 and localization verification.

**Release safeguard:** Exact-main SHA CI gates must pass before GitHub publishes APK/AAB/checksums. Its disposable signing key does **not** support updates of differently signed Play/old GitHub installations. Do not uninstall an existing QREX app just to switch builds: encrypted saved Wi-Fi secrets, favorites and history can be lost. The unsigned Play QA bundle is not Play-upload-ready; validate the original authorized Play key and unused versionCode 112 in Play Console.

Historical v1.0.0–v1.0.11 release assets remain intact. This QA does not prove pixel-identical appearance or fault-free behavior on every physical Android device.
