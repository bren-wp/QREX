# QREX v1.0.27 — Splash and Scanner UI fidelity

**GitHub release candidate:** v1.0.27 (Android versionCode 127) · package `com.brendigo.qrex` · minSdk 26 · targetSdk 36.

## Native Android screen pass
- **Screen 01 — Splash:** Retains the native Q/QR vector (no marketing mockup substituted), cyan-accented verb in the QREX wordmark/tagline, blue ribbon gradients, anchored footer and compact/large-text layout protections. The CI captures real emulator pixels.
- **Screen 02 — Scanner:** Header now accurately states that scanning happens on the device, as in the supplied design. Translated through all 23 catalog languages with generated Android resources. Original CameraX/ZXing camera/gallery, privacy, torch and zoom behavior is unchanged.
- **Quality:** Instrumentation verifies the scanner subtitle and real buttons. Existing tests for QREX storage, gallery, events, release metadata, 23 languages and the API 26/31/34/35/36 matrix remain required.

The user-supplied marketing board includes handset frames and transformed images. Actual device screenshots are checked by CI, but mathematical 1:1 equality with a perspective composite is not claimed; exact pixel comparison requires a flat registered reference image.

## Public GitHub distribution only
The publication workflow must first verify the exact `main` commit and successful native, localization and screenshot CI jobs. It builds and signs a release APK/AAB using a disposable CI-only certificate, confirms package/version/signature integrity, generates SHA-256 checksums, collects 12 genuine Android screenshot PNGs, and checks the release tag and assets.

**Important:** The public GitHub APK/AAB certificate is not the existing Google Play upload certificate. It cannot replace an installed Play app and must **not** be submitted as an authorized Play update. The `Play-UNSIGNED-QA.aab` is deliberately not Play-ready. Keep the Play signing key protected and the existing user's saved QR/history data intact.
