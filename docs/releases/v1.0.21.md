# QREX v1.0.21 — all-screen Android layout coverage

**Package:** `com.brendigo.qrex` · **Version:** `1.0.21` · **Build:** `121` · **minSdk:** 26 · **targetSdk:** 36.

The real QR Result screen now retains five accessible bottom navigation tabs. QR actions and scroll content remain above Scaffold navigation insets, and switching tabs dismisses the Result. UI instrumentation tests verify the layout and that sensitive Result data does not remain visible after switching destinations.

The screenshot QA suite now captures all ten actual Android screens at compact 320dp and standard/reference window sizes, plus eight large-font screen variants and three optional light-theme checks. Release images remain genuine 1080×1920 dark Android screenshots, not mockups. History and long forms may scroll rather than clip text.

**Release gates:** 23 offline languages; Kotlin, JUnit, Lint and R8; ten genuine screenshot PNGs with dark-pixel checks; full API 26/31/34/35/36 connected instrumentation and lifecycle stress tests; exact merged-main SHA, package identity, APK/AAB signing and SHA256 checks. This document is not evidence of publication until the GitHub release is verified.

QR content, existing History, Favorites, local Keystore-encrypted Wi-Fi records, permissions and package identity are unchanged.

**Signing caution:** public GitHub APK/AAB use disposable certificates and cannot update a differently signed Play/GitHub installation. Do not uninstall existing QREX merely to test them: local data may be erased. An official Play update needs the original authorized upload certificate and separate protected signing.

The user-supplied marketing reference boards use perspective-transformed device renders; mathematically exact pixel-for-pixel 1:1 equality is not established without flat, matched reference captures.
