# QREX v1.0.52 — DocuScan document import integration

**Status:** GitHub publication must pass all checks before this version is marked released.

QREX's existing QR and document scanning interface now includes:
- Offline PDF import from the Android system document picker.
- Multiple PDF pages appended to the existing eight-page document session.
- Bounded rendering with PdfRenderer (up to 1,800,000 pixels per page; 48 MiB file limit).
- A new adaptive **Auto enhance** filter with one-step Undo.
- Per-page **Export PNG** from the existing QREX Pages cards using Android SAF.
- Localized button labels and error messages across all 23 supported languages.
- Instrumented Android PDF and contrast-filter tests.
- Preserved QREX branding, Compose theme, camera, no-network privacy defaults
  and original document export workflow.

## Verification required before publication

signatures cannot update an installation signed with the Play certificate.
