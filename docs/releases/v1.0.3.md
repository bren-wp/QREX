# QREX 1.0.3 — Android GitHub release

**Application:** `com.brendigo.qrex` · **versionName:** `1.0.3` · **versionCode:** `103`

This GitHub release carries the UI/UX, reliability and dead-code improvements from PR #28, following the published 1.0.2 app.

## Improvements and fixes

- Improved contrast of selected navigation tabs in light theme and made scanner/QR-result branding adapt to the active theme.
- Improved History accessibility: long Wi-Fi SSIDs and QR descriptions are truncated without pushing Delete off-screen, and the empty state is clearer.
- Polished Settings and More screen with accessible minimum touch heights, a more visible Delete All action, a wider language selector, and balanced Privacy/Terms links.
- Rounded the camera preview and fixed the flashlight control: UI changes its state only after CameraX's asynchronous torch request succeeds; repeated taps are disabled during the request.
- Removed a demonstrably unused Kotlin viewport-sizing helper; retained required Keystore AES-GCM, history integrity safeguards, Flutter history migration and document exports.
- Added a privacy-oriented Wi-Fi history label test, expanded source-level quality regressions and fixed the prior GitHub 1.0.2 publisher so it cannot attempt to republish an immutable version.
- Added an Android lifecycle stress regression that recreates the Activity after 30 rapid Create → Result → Close cycles. The Android API 31 test had previously observed one intermittent Compose node-detachment crash; one retried run passed, and the expanded regression passed in the PR matrix. **This does not establish that a rare crash is eliminated on every physical device.**

## Release assets

- `QREX-Android-1.0.3.apk` — standalone signed Android GitHub APK.
- `QREX-Android-1.0.3.aab` — GitHub-signed Android App Bundle, **not** signed with the existing Google Play upload certificate.
- `SHA256SUMS.txt` — SHA-256 checksums of the two Android build artifacts.

**IMPORTANT — incompatible signing keys:** The GitHub release workflow creates a different disposable certificate for this edition. **The v1.0.3 APK cannot be installed in place over QREX v1.0.2, v1.0.1, v1.0.0 or an app previously signed for Google Play.** Uninstalling the existing app can delete saved QR codes, Wi-Fi codes and history; do not uninstall it unless you have safely exported or backed up all needed data. The disposable signing key is not kept for future upgrades.

This is a **GitHub-only** distribution. It is **not a Google Play release** and does not prove production upload signing compatibility, Play Console version-code availability, actual physical-device camera testing, or upgrade/migration acceptance. A Play update requires the existing authorized key and separately validated data-preserving upgrade process.

Earlier v1.0.0, v1.0.1 and v1.0.2 GitHub releases and assets remain available.
