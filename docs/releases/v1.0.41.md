**Published on GitHub.** The v1.0.41 APK/AAB, unsigned Play QA AAB,
12 genuine emulator screenshots and SHA256SUMS are available from the

## Reference-screen 06: More / Postavke
The actual user-supplied dark Android reference places six settings in a
2×3 grid. QREX now restores native clickable Theme, Language, Export,
Privacy, Terms and About tiles in this visual order, with bright icon plates,
full touchable cards and a separate red Clear History action.

Unlike an inflexible screenshot bitmap, the actual Compose grid becomes
single-column below 360dp, in short landscape viewports and with accessibility
text scaling ≥130%. Tablet width is constrained to a centered 560dp content
panel. Existing legal disclosures, installed app version, PDF export and
local-history deletion confirmation are preserved.

## Native Android release safeguards
- `com.brendigo.qrex` stays unchanged, minSdk 26 and targetSdk 36.
- Local CameraX/ZXing, eight QR types, encrypted saved Wi-Fi details,
  23 offline translations and five real navigation destinations are preserved.
- Release only when Kotlin/JVM/Lint/R8, real emulator screenshot capture,
  23 translations and P03 Android API 26/31/34/35/36 tests all pass on
  the exact PR head, and again on the merged main commit.
- Require APK/AAB, unsigned Google Play QA AAB, 12 genuine screenshots,
  `SHA256SUMS.txt`, version and certificate checks.

**Distribution:** GitHub packages use an ephemeral distribution certificate.
They are not Google Play update signed and cannot upgrade differently signed
installations in place. No claim of 0% visual pixel error is made without
rectified, equal-size original screenshot reference frames.
