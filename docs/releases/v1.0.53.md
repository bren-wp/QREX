# QREX v1.0.53 — Android build 153

**Status:** GitHub publication must pass all checks before this version is marked released.

## Dark-only interface and quicker document scanning

- Remove the former Light/System appearance setting, persistent theme-mode API and separate light palette. Every installed app instance uses the same dark Material3 palette and matching Android system bars.
- Expose a prominent, full-width, accessible **Document scan** button on the Scan screen rather than an icon-only header action.
- Open four-corner cropping **immediately** after new camera captures and selected gallery images. Suggest paper boundaries locally in the background and preserve any manual corner changes.
- On applying the crop, accept new pages directly into Pages with no redundant Review/Accept step. Retain re-edit, filters, Undo, perspective/rectangle controls, PDF import, multipage PDF and PNG export.
- Keep offline ZXing QR scanning, Android Keystore privacy protections, and 23 language resources.

## Audit and release gates

- Source security policy and dead-code lexical gates, Kotlin unit tests, Android instrumentation on API 26/31/34/35/36, R8/Lint, merged-permission policy, Android compatibility and actual 1080×1920 screenshot verification are mandatory.
- Require 12 actual main-screen and four real dark document-editor images. GitHub Release must contain all 16 PNGs, the GitHub-signed APK/AAB, an unsigned Play QA AAB and SHA256SUMS: **20 assets total**, validated at the exact main SHA.
- The GitHub signing certificate is disposable and **cannot** be used to update Google Play installations signed by a different identity.
- See [security/dead-code audit scope](../audits/2026-11-20-qrex-v153-dark-document-security-deadcode.md).
- Device-level security/penetration testing, OEM camera QA and 0% pixel-difference to original approved flat references remain additional verification steps.
