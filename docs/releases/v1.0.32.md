# QREX v1.0.32 — unified native Create QR card

Android: `com.brendigo.qrex`; versionName `1.0.32`; versionCode `132`; API 26+ / target API 36.

## Highest-visible structural gap: Create QR

The composite reference groups the URL input and QR preview in **one unified raised navy panel**. The current Android implementation previously used separate form and preview surfaces. The Create screen now wraps the live input, optional Wi-Fi/contact/event fields, and generated QR preview in a single native Compose panel, without replacing interactive content with an illustration. It retains the four quick tabs, overflow for all four advanced QR types, and functional 48dp clear URL action. The primary QR button and the independent Save-to-device button remain pinned and reachable on compact screens; Save gains a muted raised surface consistent with the reference.

Tests verify the actual form field is inside the unified card and the action buttons remain visible. The source contract retains all eight QR types, offline QR encoding, privacy and Wi-Fi export approval. No new network dependency, permissions, secrets logging or data migration.

The user reference is a perspective marketing montage. This release is a **measured structural alignment step**, not proof of mathematical zero-pixel deviation. Future actual screenshots must be compared at matching pixel/density coordinates before a 1:1 claim.
