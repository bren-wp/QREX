# QREX 1.0.2 — Android GitHub distribution

QREX 1.0.2 (Android `com.brendigo.qrex`, `versionCode 102`) includes the stability and privacy fixes merged through PR #26.

## Improvements
- Count padded Android `am_anr :` events correctly during privacy-redacted CI crash checks, without exporting QR data, Wi-Fi secrets or stack traces.
- Improve Result-screen bottom Close accessibility around Android 16 on-screen keyboard/edge-to-edge windows.
- Add regression coverage for physical Close-button clicks with focused input.
- Maintain offline scanning and generation, local history, Keystore encryption and 23 languages.

## GitHub assets
- `QREX-Android-1.0.2.apk` — signed standalone GitHub APK.
- `QREX-Android-1.0.2.aab` — signed GitHub AAB; **not valid for the existing Play Console upload key**.
- `SHA256SUMS.txt` — archive checksums.

**Critical signing warning:** CI generates a *new disposable signing key* for each GitHub release, does not retain it, and never uses the production Play upload key. Consequently **this APK cannot be installed in place over GitHub 1.0.0, GitHub 1.0.1 or the Google Play installation.** Do not uninstall an older installation without first safeguarding local records; uninstalling can delete saved history, favorites and Wi-Fi QR records. Previous release assets remain available.

This publication is **GitHub-only**. It does not confirm Google Play compatibility, physical-device camera/upgrade QA, Play Console version-code availability or production app-signing continuity. For a Play update, verify the actual existing track codes and approved upload certificate, and build a separate AAB using protected production credentials.
