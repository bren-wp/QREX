# QREX 0.2.3 RC1 — QR safety, clarity and preview integrity

**Android & iPhone verification build · not signed for Google Play or the App Store**

QREX scans, creates, saves and exports QR codes, including independent PDF and ZIP exports and PNG export on iPhone. There is no account, no ads and no automatic opening of scanned links.

## Improvements in this candidate

- **Consistent QR validation:** Android and iPhone reject whitespace-only QR payloads and values exceeding the supported 1,500-byte QR-generation limit.
- **Wi-Fi correctness:** A password containing only spaces remains a protected network, not an open access point. Android now matches iOS; genuinely empty passwords still represent open networks. Both have regression tests.
- **Protected history migration:** Android now removes old plaintext Wi-Fi duplicates even when the same saved code is already present as an encrypted record. Device-backed regression coverage checks that no password remains in preferences.
- **Accurate preview classification:** GitHub RC releases containing debug-signed or unsigned testing artifacts must always remain pre-releases. A GitHub Actions guard monitors published or edited RC releases and corrects misleading stable-release labels.
- **Maintained compatibility:** Existing package IDs, all 23 language resources, iOS Keychain, Android encrypted Wi-Fi history, and Flutter migration support remain in place.
- **QA checks:** The final commit must pass Android Kotlin builds/tests/lint/AAB, Swift XCTest/archive, Flutter CI, localization tests and genuine Android/iOS simulator screenshots before its RC artifacts may be published.

## Testing artifacts, not store distributions

Once all exact-commit release gates pass, downloads may contain an **Android debug APK**, **unsigned Android AAB**, **unsigned iOS device archive**, real emulator/simulator screenshots and SHA-256 checksums.

These builds are **not production signed**. Real-device camera/gallery/torch/export testing, accessibility review, upgrade/migration tests, authorized Android Play upload signing and Apple provisioning remain required for store distribution.

Exported PDF and ZIP files are unencrypted and can contain confidential QR data, including saved Wi-Fi passwords.
