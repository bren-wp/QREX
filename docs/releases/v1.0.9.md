# QREX 1.0.9 — Android startup and history protection

**Application ID:** `com.brendigo.qrex` · **versionName:** `1.0.9` · **versionCode:** `109`.

## Verified source changes planned for this release

- Protect launch against **wrong-type** `lightMode`, `historyEnabled`, and `language` SharedPreferences entries. Android normally throws `ClassCastException` when a getter expects a different type. QREX now uses safe in-memory defaults without altering the damaged key or serialized QR history.
- Safeguard the legacy Flutter migration marker and historical JSON preference type. An invalid value suspends migration instead of crashing the process, deleting old entries or marking the migration complete.
- Deletion uses the QR **payload identity** rather than a stale timestamp or saved flag. A user can toggle favorites while a Result or History row is open and still delete the intended QR without falsely reporting success.
- Added real Android instrumentation tests for encrypted-history preservation, malformed preferences, invalid migration state, and stale-favorite deletion.
- Preserved the existing responsive native Compose UI, 12 real Android screenshot references, offline CameraX/ZXing, secure Wi-Fi QR ciphertext, 23 translations and API 26–36 lifecycle matrix.

## Quality gate

Publication requires successful Kotlin unit/device tests, Android Lint/R8, privacy checks, genuine emulator screen capture and complete API matrix for the PR head. After merge the GitHub release publisher revalidates Android CI, screenshots and localization for the **exact main SHA** before publishing its assets. No claim of flawless physical-phone behavior or pixel-perfect OEM masks is made without device tests.

## Distribution / signing

The GitHub APK is signed with a **new disposable CI certificate** and cannot update differently signed QREX installs in place, including the app from Google Play or earlier GitHub builds. Do not uninstall merely to upgrade: local history, favorites and Android Keystore secrets may be erased. The GitHub inspection AAB is **not** for Play. The separately labeled `QREX-Android-1.0.9-Play-UNSIGNED-QA.aab` requires the existing authorized Play upload signing path before submission. Verify that Google Play versionCode **109** is unused.
