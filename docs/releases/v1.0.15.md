# QREX v1.0.15 — Android UI stability and verified touch targets

**Android package:** `com.brendigo.qrex` · **version:** `1.0.15` · **versionCode:** `115` · **minimum API:** 26 · **publisher:** Brendigo.

## What changed

- Fix the Result screen's **Back** button: 52dp real Compose click target withstands API 35/36 density rounding and passes the unchanged ≥48dp emulator assertion. The earlier explicit 48dp target could measure 47.999996dp on Android 15.
- Enlarge History **All** and **Saved** filters to ≥52dp, Result overflow to 48dp, and Language/PDF Export back buttons to ≥48dp. Preserve the midnight-blue/cyan QREX design, 4-tab navigation and all user flows.
- Add real Android instrumented tests measuring bounds of the four tabs, scanner Gallery/Torch, Create QR choices and Generate/Save, Result Back, History filters, More navigation, language selection and PDF Export. These complement visual hierarchy screenshot checks.
- Add a strict, offline, standard-library `tool/compare_ui_pixels.py` that can compare the ten emulator captures with original matching-size PNG references and reports exact pixel mismatch counts, channel delta and changed bounds. **It does not claim 1:1 pixel parity** until the actual user reference PNGs are provided.
- Preserve 23 offline languages, camera/gallery QR decoding, Wi-Fi data encryption, local saved/history records, PNG and PDF export, no account and no analytics.

## Verified pre-release lifecycle matrix

The corrected source passed actual emulator stability and UI geometry checks on **Android API 26, 31, 34, 35 and 36** (including the previously failing API 35), plus Android Kotlin, Lint/R8, localization and real screenshot CI. The release workflow independently requires three successful exact-`main` checks (native CI, all localizations, and genuine Android screenshots) on the versioned source commit before creating v1.0.15.

**Public download:** GitHub release distributes APK, AAB, a clearly marked unsigned Play QA AAB, 10 actual emulator PNG screenshots and SHA256 checksums. These are verified by source SHA, package/version metadata, checksums and matching APK/AAB certificate fingerprints before publication.

**Critical signing warning:** The GitHub APK and GitHub AAB are signed with an ephemeral **disposable** signer; **they cannot update** a QREX installation signed by another key or Google Play. Uninstalling the old app can erase QR history, favorites and Android Keystore-backed encrypted Wi-Fi data. The public GitHub AAB **is not Google Play-ready** and the Play QA AAB is unsigned. Authorized Play updates require the original upload key in the separate protected production workflow. Existing GitHub releases remain immutable.
