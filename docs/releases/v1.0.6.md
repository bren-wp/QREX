# QREX 1.0.6 — approved Q/QR launcher mark and calendar reliability

**Package:** `com.brendigo.qrex` · **versionName:** `1.0.6` · **versionCode:** `106`.

## Changes since v1.0.5

- Redrawn launcher as a **native vector** inspired by the supplied Oct 22 blue Q/QR icon references: stronger white Q, white QR modules, cyan scanner brackets and deep-blue fill. Supports density-independent Android adaptive and monochrome themed icons.
- The actual Compose splash screen now uses the **same full-color artwork** as the launcher icon, avoiding inconsistent, smaller monochrome imagery and unnecessary white empty areas.
- **Create QR** preview now sits immediately above the functional Generate/Save buttons instead of leaving a large gap; while the keyboard is visible, the preview collapses to preserve usable form height. The Generate and Save actions remain reachable on compact Android phones.
- **History/Favorites** rows now show directly tappable, accessible hearts for marking and unmarking favorites; the existing overflow menu still works.
- **Contact QR** supports a name, phone number and email address with correct vCard 3.0 delimiter escaping and editing. QR encoding now explicitly uses UTF-8 ECI to preserve č, ć, đ, š, ž and other Unicode characters on actual ZXing/CameraX decode.
- The splash icon is larger and rounded like the approved phone references.
- Calendar event date picker now builds the selected date atomically; switching from January 31 to a shorter month or from leap February to a non-leap year no longer calls potentially invalid intermediate dates. Added regression tests for both cases.
- Android remains fully native Kotlin/Jetpack Compose. Existing CameraX/ZXing scanning, 23 languages, dark-first design, favorites, local data, encryption and migration are preserved.

The attached UI screenshots are actual Android emulator captures after all required CI quality checks, **not** artwork mockups. The user-supplied reference boards contain different icon variations; the blue Q/QR tile from the first two is used as this release's canonical mark. Pixel-perfect similarity across all device masks and OEM launchers is not claimed without device-by-device visual comparison.

## Important signing and data protection warning

Each public QREX GitHub APK uses a fresh disposable certificate. **The 1.0.6 APK cannot upgrade an installed QREX signed with a different certificate**, including GitHub 1.0.0–1.0.5 or the Google Play app. Uninstalling old installs can delete local history, saved Wi-Fi QR codes, favorites and Android Keystore data. Never advise uninstalling before users protect data they need.

The existing Google Play upload certificate and an unused Play `versionCode` must be checked in Play Console. `106` has **not** been verified as unused in that external account. Google Play approval, physical Android QA and complete 1:1 UI comparison remain external verification steps, not automatic claims.

Published QREX history and legacy Flutter-data migration remain intact.
