# QREX 1.0.0 — Android GitHub release

**Stable source release for Android · build 100 · Kotlin / Jetpack Compose**

QREX scans and creates QR codes locally on Android. It provides on-device camera and gallery scanning, QR creation for websites, Wi-Fi and contact details, favorite codes and history, encrypted storage for manually saved Wi-Fi content, and user-initiated PNG/PDF/ZIP export in 23 interface languages.

## Important security and update information

You requested this GitHub release **without providing the existing production Google Play signing key**. Android requires APKs to be signed before they can be installed. Consequently, both packages in this GitHub release are built in **non-debug release mode using a one-time generated GitHub Actions certificate**. No Google Play upload identity or production secret is used.

- The APK can be installed directly on compatible Android devices; installing from GitHub may require allowing installation from the browser or file manager.
- **It cannot update an existing QREX installation signed with a different certificate.** In particular, users of earlier Flutter/Android distributions must **not uninstall the existing app** expecting an in-place update; uninstalling may erase local QR history and favorites. Back up or export data before changing signing identities.
- The signing key is not retained, so this GitHub APK has **no guaranteed future in-place upgrade path**.
- The AAB is **not approved for Google Play distribution**, and this GitHub release does not imply Play Console acceptance or Play App Signing compliance.
- These artifacts are **not unsigned** in the literal sense: Android installation requires signing. They are **not signed with your original production certificate**.

The Android source keeps its migration reader for the earlier Flutter history format, but in-place migration requires compatible application signing, which this self-contained GitHub release cannot guarantee.

## Privacy

QREX needs no account, ads, tracking, or application internet permission. QR scanning/generation is on-device; Wi-Fi credentials are encrypted if explicitly saved. QR URLs are not opened without confirmation. User-exported PDF/ZIP data is not encrypted—protect exported files.
