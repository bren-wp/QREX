# QREX 1.0.0 — Android only

**Production release notes. Publish only after a signed Android AAB and its SHA-256 file pass all gates.**

QREX is an Android-only local-first QR scanner/creator by [Brendigo](https://brendigo.com), built with Kotlin and Jetpack Compose.

## Features

- CameraX + on-device ML Kit scanning and scanning from the Android photo picker.
- Create QR codes for URLs, free text, Wi-Fi, contacts, phone numbers, email and locations.
- Show destinations before opening; no automatic URL execution.
- Save history/favorites locally; manually saved Wi-Fi secrets use Android Keystore AES-GCM.
- Confirm before sharing Wi-Fi QR payloads; flag their Android clipboard copy as sensitive.
- Export PNG, printable PDF and ZIP files after explicit user action.
- Adaptive Android screens and 23 supported languages.
- Preserve migration of earlier Flutter Android user history and settings.

## Distribution integrity

Only the explicitly authorized stable `v1.0.0` may ship:
- `QREX-Android-1.0.0.aab` — signed using the **existing Google Play upload key**.
- `SHA256SUMS.txt` — checksums calculated from the actual signed AAB.

Android application ID: `com.brendigo.qrex`. Version `1.0.0`, versionCode `100`.

No iOS, IPA, Flutter runtime, unsigned debug APK or QA build is a production release artifact. A signed AAB is **not** directly installable and publishing on GitHub is not evidence of Google Play approval.

## Privacy

No account or QREX cloud upload. Manually exported PDF/ZIP archives **are not encrypted**, so handle them carefully. Details: [Privacy](../PRIVACY.md), [Terms](../TERMS.md), [Support](https://brendigo.com).
