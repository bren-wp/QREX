# QREX v1.0.40 · build 140 — Result screen responsive polish

**Release candidate — do not identify as published until exact-main CI succeeds
and all GitHub release assets are present.**

### Screen 03: Result
The narrow Android phone view keeps its existing visual hierarchy: centered
result category tile, one navy summary card, primary action, accessible action
rows, save/favorite/edit/delete, and the pinned five-tab navigation.

Tablet/unfolded displays no longer stretch Result cards across the full screen:
a 520dp centered column contains the scrolling Result view. Large window
glyphs, summary card and real QR bitmap preview scale up within this column.
Small devices retain vertical scrolling, IME safety and accessible tap targets.

### Preserved features
Local CameraX + ZXing scanning, eight QR creation types, privacy confirmations
for Wi-Fi QR content, secure saved records, clipboard privacy flags, QR PNG
export, history, all 23 localizations, icon branding and the app ID
`com.brendigo.qrex` are unchanged.

### Release verification and signing
Publication requires all four exact-SHA Android workflows, Kotlin/JVM tests,
Lint/R8, API 26/31/34/35/36 instrumentation, 12 actual emulator screenshots,
APK + AAB + SHA256SUMS, and manifest/identity checks.

GitHub binaries are signed with a **new disposable CI identity**, not the
Google Play upload key. They cannot update an existing differently signed
QREX installation in place. `Play-UNSIGNED-QA` is **not** upload-ready.

Visual pixel error is not certified as 0% without matched flat source screenshots.
See [Result geometry audit](../audits/2026-11-07-qrex-result-tablet-responsive-v140.md).
