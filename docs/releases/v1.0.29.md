Android package `com.brendigo.qrex` · versionName `1.0.29` · versionCode `129` · minSdk 26 / targetSdk 36.

## Screen 04: Create QR, responsive reference pass
- Four prominent quick tabs (**Link, Text, Wi-Fi, Contact**) are text-only on regular phones ≥340dp, matching the reference; 320dp phones / 130% text use the tested two-by-two alternative. Each is an actual native Surface with a selected 3D gradient, colored rim and state semantics.
- A visible localized URL caption and a real **48dp clear input button** replace the unlabeled floating text-entry treatment. Clearing edits only the form, never persisted history.
- The Generate action has a native QR glyph and the Save-to-device action has a download glyph. Buttons stay fully actionable, enabled only for a valid QR payload and retain minimum accessible touch targets.
- Existing preview uses a **real locally generated QR bitmap**, not an embedded mockup, and stays within the scrollable form while action buttons remain reachable.
- The advanced QR formats, localized titles, Wi-Fi password entry, protected PNG export confirmation, CameraX scanning, History, Favorites and More remain functional. No new tracking or network permissions.

## Required release gates
Exact-main commit: Python source regressions, Kotlin tests, Lint/R8, API 26/31/34/35/36 instrumentation, 23-language checks, twelve actual 1080×1920 screenshot captures plus responsive screenshots, and APK/AAB signing and SHA256 integrity. If any required test fails, publication must stop.

**GitHub signing:** The APK/AAB are built with a disposable CI signing certificate and cannot safely update a Play-installed or differently signed QREX. The Play-UNSIGNED-QA AAB is NOT Google Play upload-ready. Preserve existing data and use the approved existing upload key only through the authorized separate Play workflow.

**Pixel-accuracy:** Reference is a composite marketing board with a handset frame; actual flat screens are compared at equal density and viewport before declaring measurable 1:1 pixel parity. No generated image is substituted for app UI.
