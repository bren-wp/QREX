# QREX 1.0.13 — Premium Android experience

**Android app:** `com.brendigo.qrex` · `versionName 1.0.13` · `versionCode 113` · Android API 26–36 · by Brendigo.

## What's improved

- **Premium accessibility:** Four permanently labeled navigation tabs with readable two-line localized labels; larger touch targets and improved typography on the Create, History and More screens, including compact devices and larger font settings.
- **Measurable contrast:** Unified QREX blue action surfaces meet WCAG AA for white normal text (approximately 5.12:1 contrast). A source-token contrast regression test protects future changes.
- **Faster, clearer QR creation:** Four visible quick options with accessible selected-state semantics; enlarged buttons, QR type icons and calendar date/time controls. The keyboard focus is cleared when switching tabs.
- **Reliable scanning:** CameraX and ZXing camera/gallery prioritization, progress indicator during gallery decoding, cancellation-safe bitmap cleanup, EXIF orientation and bounded image allocation.
- **Better results:** Open Wi-Fi codes no longer pretend to have a concealed password. Calendar event launch errors are reported instead of silently ignored, with CRLF-safe date/event round trips.
- **Reliability and privacy:** Preserves four primary tabs, dark premium design, PDF-only collection export, individual PNGs, saved-code history, Android Keystore Wi-Fi protection, offline-first behavior, and all **23 translations**.

## Release verification

The GitHub publisher starts only after the Android native CI has passed for the **exact `main` SHA**, checks 23-language localization and ten genuine emulator screenshots on the same SHA, and performs Kotlin unit tests, Android Lint, R8, binary signature and package/version checks. It attaches APK, AAB, an explicitly unsigned Google Play **QA** AAB, ten actual Android screenshots and `SHA256SUMS.txt`. The API 26/31/34/35/36 lifecycle matrix was confirmed for the prior merged premium PR; it is not a substitute for physical-device testing.

**Signing and installation warning:** The public GitHub APK/AAB use a **one-release disposable signing certificate** and cannot update an installed QREX signed with another certificate, including a previous GitHub release or a Google Play version. Do **not uninstall** an existing QREX installation simply to test this package: local history, favorites and Keystore-protected Wi-Fi information may be permanently lost. The public `QREX-Android-1.0.13.aab` is *not* valid as an authorized Google Play update. `QREX-Android-1.0.13-Play-UNSIGNED-QA.aab` is **unsigned** and must not be uploaded as a production bundle. Google Play releases require the original authorized upload key, fingerprint verification, manual device QA and store approval.

Historical v1.0.0–v1.0.12 tags and assets remain intact. Emulator checks do not guarantee pixel-identical rendering or flawless camera performance on every manufacturer's device.
