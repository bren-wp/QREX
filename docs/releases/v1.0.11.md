# QREX 1.0.11 — focused scanner and polished native Android UI

**Package:** `com.brendigo.qrex` · **Version:** `1.0.11` · **versionCode:** `111`.

## User experience changes

- **Four main navigation tabs:** Scan, Create, History and More. Scanning remains the start screen. Favorites are preserved in the existing encrypted/local history store and are now available through a clearly labeled **History / Favorites** filter instead of a fifth root tab.
- The saved-state UI is compatible with the original demo screenshot fixtures and existing saved QR records. Legacy restored internal Favorites page state resolves to History without deleting local information.
- Scan displays one real CameraX flashlight action alongside a prominent primary **Gallery** action. The duplicated flashlight control over the live camera viewport has been removed; the camera image still comes from the actual camera.
- The same vector Q/QR symbol and two-tone QREX wordmark used by Splash now appear in native Scanner and Create headers. The brand mark is exposed as one accessible name for screen readers.
- Maintain native responsive support for narrow/wide Android phones, enlarged fonts and IME accessibility; preserve all seven real QR types in light Create, advanced event support, camera/gallery decoding, date picker, 23 localizations and secure Wi-Fi QR ciphertext.
- Update real Android instrumented tests for four-tab navigation, discoverable saved filters, the primary Gallery/torch controls and unchanged Language/Export screens.

## Release gate

**This is a candidate, not an approved Google Play release.** Require exact-final-head Kotlin unit tests, Android lint/R8, camera/QR instrumentation, 12 real Android emulator screenshots, full P03 lifecycle matrix API 26/31/34/35/36 and 23 locale checks to pass before merging. Re-run checks on the exact merged main SHA before publishing the GitHub APK/AAB assets and `SHA256SUMS.txt`.

## Signing and data safety

GitHub release artifacts are signed with a **disposable CI key**, incompatible with installed QREX copies signed by a different certificate. **Do not uninstall** an existing app to sideload a differently signed APK: encrypted Wi-Fi QR data, favorites and history may be permanently lost. GitHub AABs are for inspection, not Google Play; the `QREX-Android-1.0.11-Play-UNSIGNED-QA.aab` is explicitly unsigned. Verify versionCode `111` is unused and apply only the authorized existing Play upload certificate for Google Play.

Previously published [v1.0.0–v1.0.10](INDEX.md) remain untouched. Actual visual pixel identity on physical OEM screens and crash-free behavior cannot be guaranteed solely from emulator CI.
