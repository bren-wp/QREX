# QREX v1.0.23 — QR contact interoperability and native Android release QA

**Package:** `com.brendigo.qrex` · **versionName:** `1.0.23` · **versionCode:** `123` · Android API 26–36.

- **Contact QR compatibility:** recognizes parameterized vCard 3.0 properties such as `FN;CHARSET=UTF-8`, `TEL;TYPE=CELL;VALUE=uri`, and `EMAIL;TYPE=INTERNET`, plus folded contact lines, without changing native QREX vCard encoding or existing QR records.
- **Visual QA:** keeps QREX's five real destinations (Scan, Create, History, Favorites, More), its ten real Android screens, and the dark Q/QR branding. UI captures are made by the running Android emulator; concept/marketing boards are not falsely treated as pixel-exact device screenshots.
- **Release pipeline:** Gradle 9.1.0, AGP 9.0.1, target API 36, optimized R8, AndroidX Fragment 1.9.1, 23 languages, Kotlin/JUnit, lint, strict permission checks, and 10 verified 1080×1920 screenshots remain required.
- **Distribution:** APK, signed GitHub AAB, unsigned Play QA AAB, ten emulator screenshots, and SHA256SUMS are included in GitHub assets.

**Signature warning:** GitHub downloads are signed with a newly generated disposable certificate and **cannot upgrade** differently signed GitHub or Google Play installations in place. The unsigned Play QA AAB is **not** suitable for Play Console; use the original authorized upload key via protected production signing. Avoid uninstalling existing builds if local history or encrypted Wi-Fi records must be preserved.

The application remains Android-only. The Apple App Store badge in marketing reference boards is illustrative, not a claim of an available iOS binary.
