# QREX v1.0.18 — QR export privacy and stability

**Android:** `com.brendigo.qrex` · `versionName 1.0.18` · `versionCode 118` · minSdk 26 · targetSdk 36.

## Improvements

- **Safer Wi-Fi PNG export:** On the Result screen, exporting a Wi-Fi QR code now asks for explicit confirmation that the generated image may include a network password. Cancelling or dismissing the warning does not open Android's document picker.
- **Correct export content:** The generated PNG uses the exact QR payload chosen and approved before the Android system file picker opens, instead of a mutable result value.
- **More reliable URL errors:** An old or malformed language preference can no longer crash the fallback error message when Android cannot open a URL.
- **Regression coverage:** Adds instrumented tests for Wi-Fi export cancellation and corrupted language settings, while retaining the existing Create, Scanner, History/Favorites, encryption and navigation tests.
- **Release documentation:** Corrects the public screenshot and release index references to the verified v1.0.17 release.

The application retains its offline CameraX/ZXing engine, four-tab navigation, 23 languages, local history, encrypted Wi-Fi QR records, no-ad policy, and existing QREX appearance.

## Integrity and testing

The GitHub publication pipeline must independently confirm the exact tested `main` commit, Kotlin and JUnit, Android Lint and R8, real emulator screenshots, localization checks, APK/AAB signatures, version identity and SHA256 checksums. PR device QA should additionally validate Android API 26, 31, 34, 35 and 36, including Create/Result stress navigation and Storage Access Framework return paths. This file is a release recipe, not proof that tests have already succeeded.

## Important signing and upgrades

GitHub release APK/AAB are signed with a **disposable per-release certificate**, which cannot update differently signed installations, including Google Play installs or earlier GitHub releases. **Do not uninstall your current installation just to update:** uninstalling can destroy local QR history, favorites and Keystore-protected Wi-Fi credentials. The public GitHub AAB and the separate unsigned Play QA AAB are **not Google Play upload packages**. An official Play update requires the existing authorized upload certificate, physical-device QA and a separately approved signing workflow.

Visual similarity to the supplied perspective promotional references is a design target, not a mathematically measured 1:1 claim.
