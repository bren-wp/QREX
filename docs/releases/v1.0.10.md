# QREX 1.0.10 — real light QR type grid and full release history

**Application ID:** `com.brendigo.qrex` · **versionName:** `1.0.10` · **versionCode:** `110`.

## Implemented in native Android

- Light Create QR now displays **seven actual functional type cards** (URL, Text, Wi-Fi, Contact, Email, Phone, Location), with QREX reference-style icon badges, pale-blue selected cards, and navy text. No new marketing images or static mockups were inserted into the app.
- Standard phones show **three columns**. Narrow phones under 360dp or with enlarged text show **two columns**, with all controls staying scrollable. Event QR creation remains available in the overflow menu.
- Dark QREX retains its four primary type chips and separate two-column compact mode. Live CameraX scanning, QR encoder, navigation, favorites/history, secure Wi-Fi data, 23 languages and Android privacy remain intact.
- UI instrumentation selects all seven light types and checks functional input selection while restoring the user's theme. Existing lifecycle/30-cycle crash regression tests remain mandatory.
- Historical QREX releases **v1.0.0 through v1.0.9** remain available with original GitHub tags, binaries and SHA256 hashes. New [release index](INDEX.md) links to each version without overwriting earlier releases.

## Release quality and packaging

Before production publication, require Android Kotlin unit tests, lint/R8, 12 genuine emulator screenshots, translation/privacy checks and API 26/31/34/35/36 stress-test matrix passing on the final commit. No assertion of pixel-perfect display across all OEMs is possible without device pixel comparisons.

GitHub provides a disposable-key signed standalone APK, inspection AAB, an explicitly unsigned Play QA AAB, screenshots and `SHA256SUMS.txt`. Disposable certificate versions are **not automatically upgrade compatible** with installed differently signed QREX copies. Do not uninstall an existing app to install a different signed APK because QR history and local secrets may be lost. Google Play requires the correct existing upload key and unused `versionCode 110`.
