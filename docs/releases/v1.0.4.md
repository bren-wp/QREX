# QREX 1.0.4 — Android performance, verified real screenshots and open-source scanner

Android `com.brendigo.qrex` · versionName `1.0.4` · versionCode `104`.

## Changes since GitHub 1.0.3

- Adopt the already-merged **fully offline CameraX + ZXing** decoder for both live camera frames and gallery images; remove Google ML Kit from the runtime. The CI F-Droid dependency gate tests the resolved release dependency graph.
- Rate-limit expensive live QR detection to approximately **one decoding attempt per 180 ms** while continuing to promptly close every CameraX frame. This aims to reduce CPU load and heat; an exact battery-life improvement has **not** been measured on physical phones.
- Capture **seven genuine QREX Android UI screenshots**, 1080 × 1920 PNG, inside the instrumented emulator workflow: Scan, Create, Wi-Fi Create, Result, History, Saved, Settings. History examples are debug-only in-memory data and are never persisted or exposed through release builds. The repo's README references actual captures included as release assets; it contains no AI UI images.
- Improve correctness checks for screenshot content, foreground QREX identity, crashes/ANR dialogs and individual asset dimensions. Preserve the existing Android 26/31/34/35/36 stress matrix, lifecycle tests, encrypted local Wi-Fi storage and migration from older Android Flutter installations.
- Update README, source/version metadata, release documentation, F-Droid status and security/performance audit with accurate past-release history.

## Downloads

- `QREX-Android-1.0.4.apk` — installable GitHub APK signed by **a temporary one-time certificate**.
- `QREX-Android-1.0.4.aab` — signed GitHub AAB for inspection, **not** signed with the existing approved Google Play upload key.
- `QREX-Android-1.0.4-Play-UNSIGNED-QA.aab` — **unsigned** Google Play *QA candidate*, built from the same commit; it must be signed with the **existing approved** upload key and revalidated before Play submission.
- `QREX-Android-1.0.4-FDroid-UNSIGNED-QA.apk` — **unsigned, not installable** FLOSS QA build after F-Droid scanner/lint. Official F-Droid signing and listing are not completed.
- `SHA256SUMS.txt` — all binary + real-screen capture checksums.
- `android-*.png` — seven 1080 × 1920 genuine captures of the installed debuggable Android app, *not generated mockups*.

**Important signing and data-loss warning:** This GitHub APK **cannot update in place** over a different-signed QREX v1.0.0–v1.0.3 or an existing Google Play installation. Uninstalling an earlier installation may erase local QR history, saved Wi-Fi codes and Android Keystore keys; do not uninstall without protecting required data. No production Play signing key is used or exported in this GitHub release.

**F-Droid:** Current source uses FLOSS ZXing instead of ML Kit. A green static dependency audit, scanner and metadata lint does **not** constitute official F-Droid publication, verified reproducible build on F-Droid infrastructure or proof of production device compatibility. The official F-Droid listing and Brendigo repository index remain separate and unconfirmed.

**Google Play:** Only a separately built bundle using the *approved existing* upload certificate and a versionCode available in Play Console can update the store track. Production device and in-place migration checks are still required.

Earlier GitHub releases remain immutable: [1.0.0](https://github.com/bren-wp/QREX/releases/tag/v1.0.0), [1.0.1](https://github.com/bren-wp/QREX/releases/tag/v1.0.1), [1.0.2](https://github.com/bren-wp/QREX/releases/tag/v1.0.2) and [1.0.3](https://github.com/bren-wp/QREX/releases/tag/v1.0.3).
