# QREX 1.0.7 — Android reference design parity and real settings screens

**Application ID:** `com.brendigo.qrex` · **versionName:** `1.0.7` · **versionCode:** `107`.

## Implemented since v1.0.6

- **Launcher icon:** split the reference blue-to-navy adaptive artwork into an edge-to-edge gradient background and a safe-zone native vector foreground. The large white Q, diagonal tail, white QR finder squares and cyan scanner brackets are carried through consistently with the QREX splash badge. Themed monochrome launcher remains supported. Launcher masks differ by Android OEM and cannot be mandated pixel-for-pixel.
- **Light theme:** explicit white/pale-blue Material3 surfaces, navy text, blue selection and subtle borders reproduce the supplied light phone reference rather than arbitrary system accent colours. **Dark** remains the default and can still be selected.
- **Camera scan:** cyan/white luminous scanner corner guide over **real live CameraX** preview, not a baked screenshot. Existing privacy handling, gallery picker, torch, zoom and offline ZXing decoder remain real.
- **Language:** a complete scrollable language screen with 23 existing offline languages plus system-language selection, native language labels, flags and accessible selection controls. Existing user language selection persists.
- **Export:** a real dedicated PDF/ZIP screen, with readable confirmation and privacy descriptions, bounded scrolling and existing user-selected Android SAF destinations. Export stays disabled when there are no saved items.
- **QA screenshots:** ten actual Android emulator captures, including Language and Export, in the existing dark-first look. The light theme also has real user-selectable UI but this capture set does **not** constitute full image-difference testing of every light/dark variant.
- **Instrumentation:** test navigation from More to both new subpages and back, preserving existing 30-cycle app lifecycle and scanner stress tests.

## Android download artifacts

- `QREX-Android-1.0.7.apk` — a GitHub-distribution APK signed using a **new disposable CI certificate**.
- `QREX-Android-1.0.7.aab` — GitHub inspection bundle signed with that same disposable certificate, **NOT for Google Play**.
- `QREX-Android-1.0.7-Play-UNSIGNED-QA.aab` — unsigned QA candidate, **NOT for Google Play without the existing authorized upload key**.
- Ten genuine `android-*.png` screenshots and `SHA256SUMS.txt`.

## Safety and release requirements

- Do **not** uninstall an existing QREX application just to install a differently signed GitHub APK. It may erase saved QR history, favorites and Android Keystore-protected Wi-Fi secrets. Disposable-key APKs cannot upgrade differently signed existing Google Play or previous GitHub installations.
- `versionCode 107` must be verified **unused** in the actual Play Console application before Play submission. The existing authorized upload certificate must be verified against Play Console and used only through the protected production workflow. Never place keystores or signing secrets in source control.
- No source-only review guarantees pixel-perfect equivalence of the user's different dark/light concept boards, all OEM launcher masks, no crash on every handset, Play policy approval or real physical device QA.
- Merge and publish only on **all green exact-commit CI**: Kotlin tests, Android lint/R8, manifest, screenshot fixture privacy checks, 10 real Android emulator images and the API 26/31/34/35/36 instrumented stress suite where applicable.
