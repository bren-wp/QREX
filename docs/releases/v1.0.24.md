# QREX v1.0.24 — responsive premium UI and history icon accuracy

**Package:** `com.brendigo.qrex` · **Android versionName:** `1.0.24` · **versionCode:** `124` · API 26–36.

### What changed
- **Reference-guided native depth:** More, result actions and other shared cards have consistent, lightweight Compose elevation instead of simulated bitmap 3D or recurring animations. Existing click targets, layouts and data are preserved.
- **Accessibility:** More settings switch from two-column cards to full-width rows starting at font scale **1.30×**; regular-size users retain the reference's two-column layout.
- **History:** phone and contact category glyphs are green, not the red reserved for deleting records.
- **Design tokens:** harmonized header and settings-card text sizes to avoid per-screen drift.
- **Regression safety:** additional pure Kotlin layout tests and Python design-contract checks; existing Android CI, Lint/R8, exact-SHA emulator captures, 23 locales and API 26/31/34/35/36 instrumentation remain in place.

### Distribution and limitations
The release publisher must attach a GitHub-only signed APK and AAB, an **unsigned** Play QA AAB, ten authentic Android screenshots, and SHA256SUMS verified against that exact release commit. **Do not upload the unsigned QA AAB to Play.** GitHub release packages use a fresh disposable signing certificate, **cannot update** existing differently signed installations, and should not be installed by first uninstalling a build containing user data. Upload a Play update only using the originally authorized upload key. No claim of mathematically verified 1:1 similarity with perspective marketing board or physical device certification is made; those checks require corresponding reference pixels and OEM testing.

QREX remains Android-only; the App Store badge in the concept board does not imply an available iOS edition.
