# QREX v1.0.31 — Language / Jezik screen

Android package: `com.brendigo.qrex`. versionName `1.0.31` / versionCode `131`, minSdk 26, targetSdk 36.

## Native screen-by-screen work

Language now has 24 fully functional choices (system + 23 offline translations) with equal-sized **36dp raised icon plates**, rounded corners, subtle colored edge and a real white-to-transparent gradient painted over opaque Material surfaces. The selected plate uses QREX blue and a stronger highlight, while inactive plates respect the system theme. Selected rows retain their semantically announced state and the radio indicator has no duplicate TalkBack click target.

The back button stays pinned while languages scroll. Selection persists using the existing local Store, leaving History, Favorites, encrypted Wi-Fi records, privacy settings and QR payloads untouched. Real Android tests verify 36dp geometry before/after selection, row alignment, scrolling, saved locale and restoration of previous settings; Python regression tests verify the full offline interaction contract.

## Mandatory exact-commit release gate

Release only from the latest main SHA when Kotlin unit tests, Android Lint/R8, all five emulator API 26/31/34/35/36 tests, 23-language catalog checks, genuine screen-capture workflow and signature/hash verification all pass. Publish GitHub-only APK, AAB, unsigned Play QA AAB, SHA256SUMS and 12 authentic emulator captures; never replace captures with image mockups. The supplied composite is a marketing montage, not an independently rectified screenshot baseline. Pixel-identical output cannot be claimed without matched screenshots.

**Important signing distinction:** GitHub APK/AAB packages use a disposable CI certificate, not the authorized Google Play upload identity. They cannot update Google Play installations or differently signed APKs without uninstalling (risking data loss). The unsigned QA AAB cannot be uploaded to Google Play.
