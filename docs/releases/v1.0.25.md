# QREX v1.0.25 — production Compose screen consistency

**Package:** `com.brendigo.qrex` · **versionName:** `1.0.25` · **versionCode:** `125` · minSdk 26 / targetSdk 36.

This release aligns the ten real Android capture routes with the supplied dark QREX direction:
- **Splash:** original Q/QR brand mark, two-tone wordmark, blue curved wave background and localized copy retained.
- **Scan:** subtle navy/cyan framed live CameraX preview, safe gallery/torch controls, preserving camera privacy.
- **Create and Wi-Fi:** native selected QR-type accent borders/elevation, readable title hierarchy and pinned Generate/Save buttons.
- **Result:** standardized title and action typography, actual Share/Copy/Favorite/Edit/Delete behavior retained.
- **History and Favorites:** text-first headers without redundant launcher icon; raised cards, genuine category icons, saved-state actions.
- **More:** plain section title; two-column card layout with accessible full-width fallback for large fonts, original working actions.
- **Language and Export:** consistent title scale and selected-language depth, real offline locale switching and PDF export.
- **UI tokens:** uniform rounded geometry, typography, 2–3dp native shadows and colors, avoiding image-based fake controls.
- **Regression:** pure screen-fidelity contract tests plus the existing Kotlin, 23-locale, R8/Lint, exact-commit emulator and API 26/31/34/35/36 test gates.

**Limitations:** Automated screenshots are actual Android Compose captures, not proof of mathematical 1:1 parity with a multi-phone perspective marketing composite. Exact pixel comparison requires separate straight-on reference images registered to matching device resolution, density, locale and state. Physical-device/OEM QA and a full security audit remain distinct acceptance steps.

**Signing:** GitHub APK/AAB use an ephemeral distribution certificate and cannot update differently signed existing/Play installations. The `Play-UNSIGNED-QA.aab` is for QA only and cannot be uploaded to Play. Do not uninstall an existing installed copy if preserving local records matters. Use the original authorized Play upload key for a Play update.
