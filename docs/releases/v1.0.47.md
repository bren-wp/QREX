# QREX v1.0.47 — Android build 147

**Status:** GitHub publication must pass all checks before this version is marked released.

## Safer QR website processing

- Introduce a platform-neutral QR web URL validation gate before Android Intent dispatch.
- Reject malformed ports, credential-bearing URLs, encoded authority tricks, unsafe schemes, and malformed domain labels.
- Preserve valid HTTPS links, internationalized domain names and IPv6 literals.
- Add pure Kotlin JVM regression tests and real Android instrumentation for the external URL gateway.

## Release and production automation

- Introduce a source-driven GitHub-only publisher, replacing one active YAML recipe per release.
- Require four successful exact-SHA workflows including P03 API 26/31/34/35/36 tests.
- Preserve disposable GitHub signing, signature equality, SHA-256 manifest, twelve authentic screenshots and unsigned Play QA bundle labeling.
- Synchronize marketing README, release archive and changelog only after verified publication.
- Keep original package ID `com.brendigo.qrex`, Google Play signing identity and offline privacy baseline unchanged.

## Distribution notice

GitHub APK/AAB packages use an ephemeral CI certificate. They are not suitable for Google Play upload, and cannot reliably update existing GitHub or Play installations in place. Do not uninstall an existing QREX installation just to replace its signature, because local favorites, history and encrypted Wi-Fi data may be lost.
